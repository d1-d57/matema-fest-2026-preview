**Итоговая раскладка (после нескольких итераций с владельцем):**

**Картинки — 16 слотов, все размечены** `data-needs-image` + поле `need:` в массиве `QUESTIONS` (каждое `need:` = что искать, «ШИРОКОЕ/16:9»). Сейчас заполнены авторскими из docx (часть низкого качества — подсолнух, рыба), 3 плейсхолдера на экранах вопроса №4/5/9 (чтобы не спойлить ответ), 2 сгенерированных узора Тьюринга (реакция-диффузия — временная заглушка). *Решение владельца:* поиск/вставку широких HQ-картинок делает Claude Code (у Cowork нет надёжного канала качать картинки из веба; веб-ограничения). Ничего не генерировать — только искать/подтягивать качество.
- Escher (№3, разбор): текущая гравюра под копирайтом — в `need:` прописана замена на общественное достояние.
