# ТЗ на доработку картинок квиза «Фракталы в природе»

Это задание для переработки картинок (например, в ChatGPT / генераторе изображений). К каждому пункту в архиве `paket-kartinki-pravki.zip` лежит файл — текущая версия с сайта (`__NOW`) и, где есть, референс (`__REF`). Нужно выдать **исправленную картинку** по ТЗ.

## Общие требования ко всем картинкам
- **Широкий горизонтальный формат.** На странице картинка растягивается во всю ширину и заполняет область; узкие/квадратные кадры обрезаются и выглядят плохо. Целься в **16:9** (можно шире, до ~2:1), высокое разрешение (**≥1600 px по ширине**).
- **Объект виден целиком и заполняет кадр.** Не узкий фрагмент. Если объект «не помещается» — **добавь фон/контекст вокруг него**, чтобы он влез в широкий кадр и не обрезался по краям.
- **Кадр заполнен изображением** — без чёрных или белых полей по краям.
- Страница тёмная (тёплый чёрный фон, палитра амбер/терракота), стиль — красивый научпоп. Картинки смотрятся на тёмном.

## 1. Подсолнух — экран вопроса №1

- **Сейчас:** макро центра подсолнуха — виден только узкий центральный «пятачок» спиралей.

- **ТЗ:** показать **бо́льшую часть соцветия подсолнуха** (в идеале всё соцветие с центром), добавить фон/лепестки/окружение вокруг, широкий кадр. Опционально — деликатно **наложить спирали-парастихи** (цветные линии семейств 8 / 13 / 21, как в референсе), чтобы читались числа Фибоначчи.
- **Формат:** 16:9, ≥1600 px.

Чистый фон. *(Про авторские права не беспокоимся — некоммерческая страница на пару сотен зрителей; можно и просто перерисовать под Эшера.)*
