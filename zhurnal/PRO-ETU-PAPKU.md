# Рабочая память — арки

Здесь живут **арки** — многосоставные работы на несколько сессий (добавить страницу, переверстать блок, серия правок). Каждая арка — папка `<ГГГГ-ММ-ДД_тема>/`, работающая как локальная память: зеркало памяти проекта внутри арки. Канон работы в арке — `../ARKA.md`.

- **`SVODKI.md`** — сводки сессий и закрытых арок, новая запись сверху. История проекта.
- **`<дата>_<тема>/`** — папка арки. Внутри:
  - `NAVIGATOR.md` — ориентация: концепция, границы, указатели. Читается первым.
  - `PLAN.md` — где мы: шаги + «СЕЙЧАС».
  - `SESSIYA.md` — дневник: деталь, решения, история (с первого хода, дистиллят).
  - `kod_<тема>.md` — канал к Claude Code (заход + вопросы + отчёт).

Вход в чат арки и хэндофф — `../ARKA.md §3, §6`. Закрытие арки (durable → `SVODKI.md`) — `../ARKA.md §7`. Что осталось только в дневнике — **не существует**.
