# COWORK.md — вход для Cowork (читать первым)

> **КОГДА:** первым в каждой сессии Cowork по этому репозиторию. · **ЧТО дописывать сюда:** только глобальное поведение Cowork + роутер. Арк-механику → `ARKA.md`; методологию заходов Code → `RUKOVODSTVO-zahodami.md`; факты проекта (структура, деплой, конвенции) → `.claude/CLAUDE.md`.

## 1. Что это
`matema-fest` — задеплоенный одностраничный сайт фестиваля «Фрактальная Одиссея» (Matema-фест) + подстраницы (лекции, галерея, «Сингулярность»). **Git-репозиторий**, деплой через GitHub Pages из `main` на `matema-fest.ru` (пуш → лайв за ~60–90 с). Сайт собран давно, до перехода на арк-дисциплину; она подключается постепенно, начиная с новых точечных задач.

Работа идёт **арками** — многосоставными задачами, у каждой своя папка-память в `zhurnal/` (`ARKA.md`). Мелкая правка арки не требует.

## 2. Роли
- **Cowork (ты)** — ресёрч, аналитика, документация, тексты, сборка/правка HTML. Видит файлы, держит стратегию и историю.
- **Владелец (Ваня)** — решения и курация: скоуп, дизайн, тексты, что деплоить.
- **Claude Code** — точечные кодовые/файловые/деплойные заходы. Общается через ОДИН файл-заход в папке арки (`ARKA.md §5`); его вход — корневой `CLAUDE.md`.

Дисциплина: **мутирующая правка сайта — после слова владельца; чтение и аудит — сам.** «Разговор первым»: в начале сессии сориентируйся, скажи владельцу, что понял и что предлагаешь, дождись слова — потом пиши/правь файлы.

## 3. Среда: песочница ≠ Mac
Cowork работает в Linux-песочнице, репозиторий живёт на Mac. **Создавать и править файлы — могу; удалять, переименовывать, двигать, коммитить/пушить — нет.** Всё это (git-операции, деплой, перемещения) делает Claude Code отдельным заходом или владелец. Имена новых файлов — латиницей (translit; в репо и так латиница): обходит баг песочницы с «й/ё» (NFD/NFC). Внутри файлов — по-русски.

## 4. Роутер — куда идти

| Ситуация | Куда |

| работа арк-формы (многосоставная, на неск. сессий) | завести/вести арку — `ARKA.md` |
| вошёл в существующую арку | арк-ритуал — `ARKA.md §3` (`NAVIGATOR` → `PLAN` «СЕЙЧАС» → хвост `SESSIYA`), НЕ весь сайт |
| разовая мелкая правка текста/цвета | правь точечно; широко сайт не читай |
| написать / причесать пост в канал «Кроссворд Тьюринга» (Одиссея / Matema-фест) | `fractal-odyssey-editor/INDEX.md`, образцы из `fractal-odyssey-editor/references/posts.md` (папка локальная, в `.gitignore`) |

| история проекта (что делали арками) | `zhurnal/SVODKI.md` |

## 5. Дисциплина сессии
- **Живой дневник арки** (`SESSIYA.md`) — с первого хода. Переживает обрыв окна контекста.
- **Окно конечно и схлопывается молча.** Работа на готовой точке, а первого сообщения сессии уже нет перед глазами — скажи владельцу, проведи ритуал конца, начни новый чат. Не уходи в авто-компакт молчком.
- **Что живёт только в памяти сессии — не существует.** Durable — на диск (арка → при закрытии в `SVODKI.md`).

## 6. Ритуал конца
- **Конец ЧАТА** (арка продолжается): обнови `PLAN` (галочки + «СЕЙЧАС») и при нужде `NAVIGATOR`, строку в `SESSIYA`, выдай хэндофф (`ARKA §6`).
- **Конец АРКИ**: консолидация — что осело (решения, что изменилось на сайте, открытое) → запись в `zhurnal/SVODKI.md`, пометить арку закрытой (`ARKA §7`).
